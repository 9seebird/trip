# Stayflow 독립 호스팅 버전

최신 수정 사항을 포함한 프론트엔드 목업입니다. ChatGPT/Sites 로그인이나 서버·DB가 필요하지 않습니다.

## 실행 및 재빌드

Node.js 22.13 이상을 설치한 후 이 폴더에서 실행하세요.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

배포할 파일은 `dist/`에 생성됩니다. 웹호스팅에는 이 폴더의 **내용물**을 업로드하세요. `npm run preview`로 빌드 결과를 로컬에서 확인할 수 있습니다.

## 호스팅

정적 HTML/JS/CSS를 제공하는 웹호스팅에 올리면 됩니다. 도메인 루트 또는 `/stayflow/` 같은 하위 폴더에 사용할 수 있습니다. 하위 폴더 주소는 마지막 `/`를 포함해 접속하세요. PHP·Node 서버 설정이나 SPA 재작성 규칙은 필요하지 않습니다. HTML을 더블클릭하는 `file://` 실행 대신 HTTP/HTTPS로 열어 주세요.

빌더 서비스에서 HTML 블록만 붙여넣는 방식으로는 전체 앱을 실행할 수 없습니다. 파일 업로드나 별도 정적 호스팅이 필요합니다.

## 기존 데이터 옮기기

기존 Sites 주소에서 **데이터 내보내기**를 먼저 실행하고, 새 사이트에서 **데이터 불러오기**로 그 JSON 파일을 선택하세요. 주소가 달라지면 브라우저 저장 공간도 분리됩니다. 배포 파일에는 사용자의 브라우저에 저장된 사진·메모가 포함되지 않으며 기본 가상 숙소 데이터로 시작합니다.

각 방문자의 입력은 해당 브라우저에만 저장됩니다. 여러 사람이 접속해도 데이터는 공유·동기화되지 않습니다. 사진 밝기·대비 조절은 미리보기 전용입니다. 기본 참고 사진은 배포 파일에 포함된 자리표시 이미지(`covers/`)이므로 인터넷 연결 없이도 표시됩니다.

## 포함 기능

촬영 일정, 사진 업로드/분류/삭제, 필수 컷 확인, 보정·검수, 사진별 수정 이력, 수정 선택/해제와 필터 연동, 채널 게시 체크리스트, 백업 내보내기/불러오기를 포함합니다. AI 검사는 시뮬레이션입니다.

## AX(AI·자동화) 반영

- 대시보드 **AI·자동화가 지금 처리할 수 있는 일**: 동선 묶기·자동 분류·사전 검수·캡션 초안 후보 수를 더미 데이터에서 계산해 표시
- 각 워크스페이스 상단 **AX 시나리오 배너**: 이 단계에서 자동화되는 일과 담당자가 결정하는 일을 구분
- 콘텐츠 상세의 **AX 인사이트**: 현재 단계·데이터 상태에 맞춘 자동 처리 / AI 제안 / 사전 점검 항목 (`app/ax-model.ts`, `tests/ax.test.ts`)
- 하단 **AX 개선 아이디어 · 구현 범위** 표: 단계별 업무 문제, 개선 방식, 목업 범위, 검증 지표와 3단계 도입 로드맵

배포 방법은 `DEPLOY.md`를 참고하세요.

원래 Sites 배포 설정과 인증 연동은 독립 버전에서 제거했습니다. 기존 Sites 프로젝트는 변경하지 않았습니다.
